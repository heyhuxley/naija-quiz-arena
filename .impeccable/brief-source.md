# Naija Quiz Arena page redesign

Scope: the public homepage, guest entry and play flow, and host workspace. The homepage is Persuade; guest play and host tools are Operate. Audience: Nigerian guests joining without accounts, plus approved hosts running a shared 15-question session. The homepage's action is joining with a six-character code. Guest success is answering privately and seeing a personal result; host success is setting up and guiding the shared session. Preserve the existing authentication, approval, moderation, session, timing, answer, and result behavior. Keep the simulated NGN prize ladder explicitly non-cash. No unresolved product decisions.

## Direction contract

THESIS: Treat the host-led quiz as one open, shared volume: entry, private answers, and the fifteen-question run are connected by a visible stitched spine, not broadcast spectacle.

OWN-WORLD: Near-white rag paper, dark ink, linen thread, restrained forest green and book-board brown. Use an open-spread composition, fine full rules, editorial book lettering for display, and plain sans-serif controls. The stitch is the signature, not decoration.

STORY: The homepage explains the free Nigerian quiz and puts the join code first. Guests follow one clear path through lobby, question, reveal, and private result. Hosts get a literal, calm workspace for setup and live control; no visual flourish obscures state.

FIRST VIEWPORT: Home is one two-page spread: wordmark and headline above a six-character join form on the left; a fifteen-link question path runs along the exposed gutter on the right. Guest entry pairs code and display-name fields with one join action; active play puts question, progress, and four large answers first. Host opens with the session list and creation controls, then the selected session and question bank in distinct work areas.
